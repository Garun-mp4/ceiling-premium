# ПОЛЕ — архитектура спокойного пространства

Approved direction: architectural minimalism, warm white #F7F5F0, white #FFFFFF, mineral #EEECE7, graphite #202220, secondary #61615B, rules #D9D7D0 and orange #FF7A18. Primary actions are charcoal with white text; orange uses dark text. No blue glows, gradient chrome, decorative counters or repeated card grids.

Manrope 400–600 headings; Onest 400–600 body, self-hosted Cyrillic/Latin WOFF2. Body 16–18px, headings fluid; hero 34–80px, maximum 2–3 authored lines. Container 1280px, desktop gutters 40–64px, mobile 20px, section separation 96–128px desktop and 56–72px mobile. Large media radius 18–22px, controls 10px. Flat surfaces with thin rules; shadows reserved for floating controls.

Home is Persuade: product-specific headline and bright close-ceiling photograph; projects lead before technologies and cost. Text and media are adjacent, never dark text overlays obscuring ceiling details. Alternate open editorial rows, large images, one dark lighting section, and compact functional modules. Each source image must match its technical specification.

Interior framing prioritizes the ceiling: hero, project cards, covers, project details and installation photography align to the top of the source. Construction close-ups keep a centered crop to preserve the junction. The installation frame uses 2.1:1 on desktop and the full 3:2 source on mobile, keeping the ceiling, the installer's head and hands visible. Review both layouts when replacing photography.

Desktop header 76px, mobile 64px. Keyboard focus uses a strong contrasting ring. Targets >=44px. All interactions have hover, focus, active, busy and error states where applicable. Native disclosure FAQ, native dialog image viewer, small interruptible transitions 160–200ms. Reduced motion disables optional movement. Content stays available without JS; mobile messenger panel respects safe area and hides while form controls are focused.

Motion: CSS and WAAPI only, no animation framework. Shared project/solution photographs transition across pages where supported; only the selected card receives a shared name. Initial hero movement keeps the image fully visible. Below-fold photo entrances run once (600ms), UI entrances/exits stay within 160–280ms and use the strong ease-out curve. Native disclosure height transitions are progressive enhancement. Keyboard actions are immediate; reduced motion keeps only a short opacity response. Submission states use a real waiting indicator, a confirmed check, a recoverable error and a separate unconfirmed-delivery state. Input values and calculator totals never animate. Mobile contacts hide while the result panel is focused.

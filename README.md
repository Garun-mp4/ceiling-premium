# ПОЛЕ — потолки и свет

Многостраничный сайт на Astro, статический HTML и небольшие модули TypeScript. Python Function `POST /api/lead` доставляет обращения в Telegram. Без React, CMS и клиентской маршрутизации.

## Локальный запуск

Требуются Node.js 22.12+ и Python 3.12+.

```sh
npm ci
npm run dev
npm run check
npm test
npm run build
npm run preview
```

Astro dev/preview обслуживает страницы, но не Python API. API проверяется unit/HTTP-тестами, через Vercel preview или `vercel dev` с серверными переменными. Никогда не коммитьте `.env*` с реальными значениями.

## Настройки формы

В Vercel для Production и Preview должны присутствовать:

- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` — бот и получатель; получатель должен начать диалог с ботом или добавить его в чат.
- `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` — Redis REST. Переменные интеграции Vercel `KV_REST_API_URL`, `KV_REST_API_TOKEN` также поддерживаются.
- `RATE_LIMIT_SALT` — случайный секрет не короче 32 символов; единый для окружений, использующих один Redis.
- `PUBLIC_YANDEX_METRIKA_ID` — необязательный публичный номер счётчика. Пока он пуст, Метрика не загружается. После настройки скрипт загружается только при согласии посетителя; Вебвизор выключен, контакты в события не попадают.

Redis работает на бесплатном тарифе без автоматического перехода на платный. Сбой Redis закрывает автоматическую отправку, прямые контакты остаются доступны. Не заменяйте общий лимит памятью функции. Redis хранит только счётчики, случайные идентификаторы и HMAC-хеши: лимит на 60 секунд, состояние доставки на 600 секунд. Подтверждённый повтор получает тот же ответ; при неопределённом результате Telegram автоматического повтора нет.

Формат запроса: `phone`, необязательные `name` и `comment`, `privacyConsent: true`, `consentVersion`, UUID `requestId`, `source`, относительный `page`, необязательные `calculator` и `utm`, пустое поле `website`. Сервер пересчитывает стоимость. Ответ успеха: `{ "ok": true, "requestId": "..." }`. Ошибки — JSON с `ok: false` и стабильным `error`; лимит возвращает 429, ожидание доставки — 409/502. Тела больше 16 КБ не принимаются.

## Редактирование

- `src/data/site.ts`: контакты, навигация, процесс, FAQ, отзывы.
- `src/data/content.ts`: шесть проектов и шесть решений, их комплектации и связи.
- `data/pricing.json`: единая модель тарифов для браузера, сборки и Python. После изменения запустите тесты и пересоберите сайт.
- `src/styles/global.css`: токены и стили. Согласованные принципы — в `DESIGN.md`, продукт — в `PRODUCT.md`.
- `src/pages/privacy.astro`, `consent.astro`: согласованные плейсхолдеры оператора. До реального юридически готового сбора данных необходимо заполнить реквизиты и проверить применимые требования к локализации/передаче и фактические сроки удаления в Telegram. Автоматического удаления переписки сайтом нет.

## Изображения и логотип

24 самостоятельных исходника созданы встроенным imagegen. Полные промпты — `assets-source/prompts.md`, размеры и SHA-256 — `assets-source/manifest.json`. Оригиналы PNG сохранены локально в `assets-source/`, исключены из Git и публикации. Версии для сайта AVIF/WebP (480/800/1200/1600 px) и JPEG находятся в `public/media/` и включены в репозиторий. Утверждённый знак сохранён; оптимизированные экспорты — `public/brand/`.

`npm run assets` повторно экспортирует оригиналы через sharp и загружает локальные WOFF2 из Google Fonts вместе с OFL-лицензиями. Для этой команды нужны локальные PNG и оригиналы логотипа в `images/brand/`. Обычная сборка их не требует. Не создавайте новые фотографии техническим скриптом: он выполняет только экспорт.

## Проверка и публикация

`npm test` проверяет расчёт и сервер по общим сценариям, телефоны, согласие, ограничения запроса, обработку сбоев и повторов. `npm run build` проверяет один h1, canonical, внутренние ссылки и все 24 набора изображений. Дополнительная браузерная проверка: откройте сайт через `playwright-cli`, затем `playwright-cli run-code --filename=tests/browser-smoke.js` (локальный preview; отправки подменяются только в тесте).

Vercel автоматически собирает Astro и Python Function. Исходники изображений, тесты и старые ресурсы исключены из публикации и пакета API. Preview получает noindex и robots Disallow; основная публикация — canonical на ceiling-premium.vercel.app. Старый `/privacy.html` перенаправляется на `/privacy/`, прежние якоря главной сохранены. Откат — стандартный rollback Vercel на предыдущую READY-публикацию; историю Git не переписывать.
